# MOPPY ROBOT PROJECT COMPLETION PLAN
# Autonomous Wallet Detection and Mapping System

## PROJECT OVERVIEW
Build a robot that autonomously explores an area, detects wallets using computer vision,
records their positions on a SLAM-generated map, and creates a blueprint showing wallet locations.

## CURRENT STATUS ✅
- Robot movement: WORKING (teleop control via keyboard/joystick)
- LiDAR connection: WORKING (RPLiDAR A1M8 connected)
- Wallet detection: WORKING (YOLO model can detect wallets from camera)
- Basic systems: Robot base, camera, sensors all functional

## COMPLETION PHASES

### PHASE 1: SLAM MAPPING SETUP (Week 1)
**Goal: Get the robot creating maps of its environment**

1.1 Test SLAM System
   - Launch robot: `ros2 launch andino_bringup andino_robot.launch.py`
   - Start SLAM: `ros2 launch andino_slam slam_toolbox_online_async.launch.py`
   - Manually drive robot around to build initial map
   - Save map: `ros2 run nav2_map_server map_saver_cli -f test_map`

1.2 Verify Map Quality
   - Check map in RViz: `ros2 launch andino_bringup rviz.launch.py`
   - Ensure LiDAR data is clean and mapping works properly
   - Test in different environments/rooms

### PHASE 2: AUTONOMOUS NAVIGATION (Week 2)
**Goal: Robot can move autonomously and explore areas**

2.1 Setup Navigation Stack
   - Test navigation with existing map:
     `ros2 launch andino_navigation bringup.launch.py map:=/path/to/test_map.yaml`
   - Verify robot can navigate to goal points autonomously

2.2 Implement Exploration Algorithm
   - Create exploration node that:
     * Identifies unexplored areas on the map
     * Sets navigation goals to explore systematically
     * Covers the entire accessible area
   - Options: Use frontier exploration or grid-based exploration

### PHASE 3: VISION-SLAM INTEGRATION (Week 3)
**Goal: Integrate wallet detection with mapping system**

3.1 Create Wallet Detection Node
   - Modify existing YOLO detection script to work as ROS2 node
   - Node should:
     * Subscribe to camera images
     * Run YOLO detection
     * Publish detection results with confidence scores
     * Include timestamp and camera pose information

3.2 Position Calculation System
   - Create node to calculate wallet world coordinates:
     * Get robot's current pose from SLAM
     * Get camera intrinsic parameters
     * Convert pixel coordinates to world coordinates
     * Account for camera mounting position/angle on robot

3.3 Map Annotation System
   - Create system to mark wallet positions on map:
     * Store wallet detections with world coordinates
     * Add markers to visualization (RViz)
     * Maintain database of found wallet locations

### PHASE 4: DATA PERSISTENCE & BLUEPRINT GENERATION (Week 4)
**Goal: Save and visualize wallet locations permanently**

4.1 Database System
   - Implement wallet location database:
     * Store: timestamp, world coordinates, confidence score, image snapshot
     * Use SQLite or simple JSON file for persistence
     * Include map metadata (map name, creation time, etc.)

4.2 Blueprint Map Generator
   - Create script to generate blueprint-style maps:
     * Load SLAM-generated map (PGM/YAML format)
     * Overlay wallet position markers
     * Add legend, scale, timestamp
     * Export as high-quality PNG/PDF
     * Include summary statistics (number of wallets found, search area, etc.)

### PHASE 5: SYSTEM INTEGRATION & TESTING (Week 5)
**Goal: Complete end-to-end system testing**

5.1 Main Control Node
   - Create master node that orchestrates:
     * Start SLAM mapping
     * Begin autonomous exploration
     * Monitor for wallet detections
     * Record positions and update map
     * Generate final blueprint when exploration complete

5.2 User Interface
   - Simple command-line interface:
     * Start/stop exploration
     * View current status
     * Generate blueprint on demand
     * Show statistics (wallets found, area covered, time elapsed)

5.3 System Testing
   - Test complete workflow in controlled environment
   - Place test wallets in known locations
   - Verify accuracy of position recording
   - Test edge cases (multiple wallets, partial occlusion, etc.)

## TECHNICAL IMPLEMENTATION DETAILS

### Key ROS2 Nodes to Create:
1. **wallet_detector_node**: YOLO detection as ROS2 service/topic
2. **position_calculator_node**: Convert detections to world coordinates  
3. **map_annotator_node**: Add wallet markers to map visualization
4. **exploration_controller_node**: Autonomous exploration logic
5. **blueprint_generator_node**: Create final annotated maps
6. **mission_control_node**: Main orchestration and UI

### Key Topics/Services:
- `/wallet_detections` - Wallet detection results
- `/wallet_positions` - World coordinate positions  
- `/exploration_goals` - Next exploration targets
- `/map_annotations` - Markers for visualization
- `/mission_status` - System status updates

### Required Dependencies:
- OpenCV (image processing)
- TensorFlow/PyTorch (if modifying YOLO)
- SQLite (database)
- Matplotlib/PIL (blueprint generation)
- NumPy (coordinate transformations)
